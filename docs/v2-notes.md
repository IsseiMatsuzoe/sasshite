# v2 / v2.1 の変更メモ

第1回比較（合成12場面）では追加指示なし・簡潔さの指示との差が出なかった。第2回として、実際の不満に近い16場面（長い作業文脈・報告・議論・誤った前提・削除指示など）を作り、GPT-6.2 Sol で生成し、利用者本人が条件を伏せて A/B 比較した。

## 本人の盲検比較の要旨
- 旧版は、Sonnet の追加指示なしに対して 8 組中 2 組しか選ばれなかった（Sol の日本語の読みづらさが主因）。
- v2 は Sol の追加指示なしに 4/4 組、Sonnet の追加指示なしに 3/4 組で選ばれた（組数が少ないため方向の確認にとどまる）。
- 機械指標（1回答あたり）: していないことの宣言 0.60→0.21、ログ・hash・パスの混入 0.23→0.02。

## 変更点
- 状態を読み手の目的で言い、「〜していません」型の宣言をやめる。
- 留保は、読み手の判断・行動とセットにする。
- 取り消しにくい操作で前提が誤っているとき、できないことと、対応が変わる選択は先に伝える。
- 読み上げて聞ける日本語（結論先行、主題の堂々巡りを避ける、読点を減らす）。
- 個別の言い回しの好みは `skills/sasshite/references/phrase_prefs.tsv` に溜め、同じ理由が3件以上たまったら原則へ統合する。

## 既知の限界
- 削除など責任の線引きに関わる判断（確認の要否）は伝え方の問題を超えるため、各担当の指示（SOUL / AGENTS.md）で決める。sasshite の対象外。
- 評価は小規模で、生成は 1 モデル、採点の一部は自動採点。過学習の確認用に新しい場面での再試験が必要。
